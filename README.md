# 🧮 Accessible Calculator

A fully accessible calculator built with vanilla JavaScript, featuring theme toggle and keyboard support.

## ✨ Features

- ➕➖ Basic operations (+, -, ×, ÷)
- ⌨️ Keyboard and mouse input  
- 🌙 Light/Dark theme with localStorage persistence
- 🔄 ± (sign toggle) and % (percent) functions
- 📜 Calculation history with clear option
- ♿ Full accessibility support (ARIA labels, keyboard navigation)
- 📱 Responsive design





## 🛠️ Technologies Used

- HTML5
- CSS3 with CSS Grid
- Vanilla JavaScript (ES6+ features)
- GitHub Pages for deployment
